# Social Media Sentiment Analyzer

## Project Overview
Analyzed social media data to identify sentiment patterns and engagement trends using data analytics and Natural Language Processing (NLP).

## Tools & Technologies
- Python (Pandas, TextBlob)
- Microsoft Excel
- Natural Language Processing (NLP)
- Power BI / JASP (exploratory analysis)

## Key Tasks
- Cleaned and preprocessed social media data.
- Classified text into Positive, Negative, and Neutral sentiments.
- Generated sentiment scores using TextBlob.
- Created interactive Excel dashboards to visualize sentiment and engagement trends.

## Project Outcome
Prepared structured datasets and analytical insights to support sentiment analysis and further application development.
